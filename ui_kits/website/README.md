# Website UI kit — SiMAF

Recreation of the institutional research-group website. Journal-style register: serif hero, hairline rules, muted paper background, spectrum palette reserved for data viz and category markers.

## Components

- `Header.jsx` — sticky masthead with logo, nav, language toggle
- `Hero.jsx` — serif display title + lead, date rules, optional logo mark
- `ResearchLines.jsx` — list of research areas with numbered eyebrows
- `Publications.jsx` — journal-citation list with year rail
- `People.jsx` — grid of researchers
- `Footer.jsx` — address, contact, institutional links

## Screens (via `index.html` tabs)

1. **Home** — hero + research lines teaser + latest publications
2. **Research** — full research lines
3. **Publications** — dense listing, filterable by year
4. **People** — PI, postdocs, students
